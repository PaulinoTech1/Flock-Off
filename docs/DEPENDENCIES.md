# Flock-Off Dependency Manifest

Every external dependency, browser API, and platform feature this site relies on.
If any of these break or are removed, the site breaks. Review quarterly.

## Runtime dependencies (npm)

**None.** The site ships zero npm dependencies. All JavaScript is hand-written
vanilla JS. This is intentional: fewer dependencies, fewer supply-chain risks,
nothing to update.
